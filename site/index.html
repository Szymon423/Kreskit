Kreskit
Open the app GitHub

Mark up a screenshot in seconds

Paste a screenshot, add arrows, notes, highlights and CAD-style dimensions, then copy it straight back out. Everything you draw stays editable.

Try it in your browser Source on GitHub

No sign-up, nothing to install. Your images never leave your computer.

What it can do

More capable than a paint program, far lighter than an image editor.

CAD-style dimensions

Linear, radius and diameter dimensions with arrows and extension lines. Drag between two points and type the value.

The tools you reach for

Rectangle, ellipse, line, arrow, pen, highlighter and text, each on a single key.

Nothing is baked in

Select anything later to move, resize, rotate, recolour or delete it. Undo and redo cover every step.

Snapping

Shapes and dimension points align to each other and to the image edges, with guide lines showing what they caught.

Out in any format

Copy to the clipboard, or export PNG, JPG, SVG or PDF. Save a project file to keep editing later.

Desktop and browser

A small desktop app built with Tauri, and the same editor running right here in the browser.

Before and after

A plain screenshot, and the same one a minute later.

How it was made

Kreskit is vibe-coded, and says so. The code was written by an AI assistant and directed by a human, who decided what the app should do and tested every stage by hand. It is a personal tool shared as it is, not an audited product.
